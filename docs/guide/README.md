# The Secure Net guide

`secure-net-guide.pdf` explains what Secure Net is, how it is built, how it works and how to use
it, for technical and non-technical readers. It is also offered for download on
[comutability.org](https://comutability.org/protocol).

The PDF is made from `secure-net-guide.html` (one file, diagrams drawn as inline SVG) by printing
it to A4 from a Chromium browser with backgrounds on. The Inter typeface should be installed.

The guide describes the main branch and, clearly marked, proposals that are still open pull
requests. Where it and the specification in `spec/` differ, the specification is right: please
open an issue. Update the edition date on the cover whenever the content changes.

Prepared with an AI assistant at the founder's request. Not independently reviewed.
