## Problem

Secure Net's specifications have so far changed whenever its first application needed them to.
Other developers can't build on a protocol that changes without notice or review, and a protocol
steered by one application will only ever serve that application.

## Proposal

Adopt [GOVERNANCE.md](../GOVERNANCE.md): numbered public proposals, examination by maintainers
and independent developers, a reference implementation with tests, a recorded decision by a
Technical Steering Committee, and inclusion in a versioned specification only after review.
Breaking changes need a higher threshold and a published migration plan. AI may prepare
proposals but not vote.

## Compatibility

No change to the protocol itself.
